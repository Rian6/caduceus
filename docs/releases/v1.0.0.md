# Caduceus v1.0.0

Primeira versão para Windows x64.

## Recursos

- Biblioteca local SQLite, capas, edição e importação de jogos.
- Downloads e importação de ISOs para o servidor OPL.
- Configuração de rede, porta e armazenamento do servidor.
- Importação de catálogos e backup SQLite.
- Temas claro e escuro e tutorial de primeira abertura.
- Consulta de conquistas do RetroAchievements com login salvo usando a proteção do Windows.

## Instalação

Baixe e execute `Caduceus-Setup-1.0.0-x64.exe`. O aplicativo abre com uma base vazia: adicione seus jogos ou importe um catálogo em Configurações.

O pacote não inclui contas, chaves de API, caches pessoais, ISOs ou saves. Atualizações preservam a base e as configurações já existentes do usuário.

## Observações

- O PS2 precisa ter o OPL configurado; o aplicativo inclui um guia de conexão.
- A integração RetroAchievements é somente de leitura.
- Instalador sem assinatura digital de certificado de editor.
- `SHA256SUMS.txt` contém o hash para conferir a integridade do instalador.
